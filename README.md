## Featured projects

### [CareerRoadmap — AI-Powered Career Recommendation](https://github.com/Bitstorm-21/ai-powered-career-recommend)
A career-roadmap and resume-parsing platform with a **Spring Boot** backend and a **FastAPI** AI service. The AI service extracts resume text from PDFs and supports skill matching and analysis; the application uses PostgreSQL.

**Spring Boot · FastAPI · Python · PostgreSQL · JWT**

### [Paimana — Project Intelligence Backend](https://github.com/Bitstorm-21/Paimana-Backend)
A backend and ML-integrated project for monitoring infrastructure project progress and surfacing risk insights. The documented design combines a Java/Spring backend with a Python ML service.

**Java · Spring Boot · Python · FastAPI · Machine Learning**
